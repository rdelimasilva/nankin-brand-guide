Quando criar uma sub-marca

Por princípio, evitamos sub-marcas. Cada nova feature, cada parceria, cada vertical cabe sob "Nankin". Sub-marca só se justifica quando:

  • O público-alvo é claramente diferente (ex: Nankin para construtoras, no futuro).
  • A oferta é separável e tem ciclo de venda independente.
  • Co-marketing com terceiro requer um nome neutro.

Mesmo aí, o padrão é "Nankin + adjetivo" (ex: Nankin Studios, Nankin Fellows), não nome novo.

Co-branding

Quando aparecer ao lado de outra marca: Nankin sempre à esquerda, separadas por barra vertical de mesma altura. Nunca dentro de container colorido. Veja exemplos em Logos.
