F3 · Fundações · Radii

Geométrico, sem flourish.

Raios pequenos para UI, médios para cards, pill para tags. Sem cantos arredondados decorativos.

--r-0

0px

Bordas vivas. Listras, divisórias.

--r-sm

4px

Inputs, tags, badges.

--r-md

8px

Botões, cards, alerts.

--r-lg

12px

Modais, popovers.

--r-xl

20px

Hero cards editoriais.

--r-pill

999px

Avatar, switch, pill button.

Não faça

  • Não misture raios diferentes em elementos vizinhos. Card com r-md → input com r-md, não r-sm.
  • Não use border-radius assimétrico ("4px 12px 4px 12px"). Sempre uniforme.
  • Avatar é sempre pill (--r-pill). Foto de perfil é sempre redonda — não há exceção.
