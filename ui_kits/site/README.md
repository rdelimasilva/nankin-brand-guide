# Nankin — Site UI Kit

A minimal marketing-site recreation, built strictly from the brand identity manual. Treat as plausible / canonical Nankin website surfaces, not a recreation of an existing live site.

## Files
- `index.html` — homepage with hero, work grid, contact strip, footer.
- `Nav.jsx`, `Hero.jsx`, `WorkGrid.jsx`, `ContactStrip.jsx`, `Footer.jsx` — components.

## Visual rules followed
- Coral hero, paper section, black footer.
- Wordmark lockup top-left, persistent nav.
- Sentence case, no emoji, no gradients, hairline borders.
- Editorial 12-col layout, generous whitespace.
